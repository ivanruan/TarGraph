# 🚀 TarGraph

**TarGraph** is an innovative, developer-first diagramming tool that bridges the gap between code and visuals. It allows users to **create, edit, and visualize diagrams using both textual code and a graphical interface**, all in real time and fully synchronized.

Unlike traditional tools that force you to choose between code-based or drag-and-drop diagramming, **TarGraph gives you the freedom to do both — seamlessly**.

---

## 🔧 Key Features

- ✏️ **Bi-directional editing** – Changes in code are instantly reflected in the diagram, and vice versa.
- 🔄 **Live synchronization** – Keep your diagrams and code in sync without manual updates.
- 🧩 **Supports core UML diagrams** – Starting with **use case** and **activity** diagrams, with more coming soon.
- 💻 **Visual Studio Code integration** – Edit diagrams inside VS Code through a native extension.
- 💾 **Export to SVG, PNG, PDF, or clean text format**.
- 📤 **Import from PlantUML or Mermaid (planned)** – Easily migrate existing diagrams.
- 🌐 **Web-based editor** – Intuitive UI powered by modern web technologies.

---

## 💡 Why TarGraph?

While tools like PlantUML or Mermaid offer code-based diagramming, they lack interactivity and live graphical editing. On the other hand, graphical editors like draw.io are user-friendly but not ideal for developers who prefer code and version control.

**TarGraph combines the best of both worlds** — making it a perfect fit for agile teams, software architects, and documentation-driven developers.
